🟩 Craft Launcher

build passing v1.0.0 MIT License

新一代 Minecraft 启动器，基于 Rust + Tauri 构建。极致的启动速度、干净的界面、原生的模组支持。

支持 Windows 10+ / macOS 11+ / Linux（AppImage / deb）。

✨ 特性

  • ⚡ 启动速度比原版启动器快 3 倍，内存占用低于 100MB
  • 📦 一键安装 Fabric / Forge / NeoForge / Quilt 模组加载器
  • 🧩 内置模组市场，支持 CurseForge 与 Modrinth 源
  • 🔑 微软账号正版登录，支持多账号切换
  • 🎨 皮肤预览 / 披风管理 / 服务器延迟测速
  • 🛡️ 完全开源，零遥测，本地配置不联网

📥 下载与安装

下载最新版本，解压后直接运行 CraftLauncher.exe 即可，无需安装 Java（内置 JRE 21）。

🔧 从源码构建

cargo tauri build — 需要 Rust 1.75+ 与 Node.js 18+。
