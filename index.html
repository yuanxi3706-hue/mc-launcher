Genshin Impact Launcher

A lightweight, open-source launcher built with Rust + Tauri. Supports Windows, macOS and Linux.

✨ Features

· 3x faster startup than official client
· Automatic game file integrity check
· Multi-account switching
· Zero telemetry, fully open source

📦 Installation

Download the latest release below, extract and run ./launcher.
